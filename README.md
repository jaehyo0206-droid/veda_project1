VEDA Project 1 - 학생 및 출결 관리 시스템

C++과 Qt를 활용하여 개발한 **학생 정보 및 출결 관리용 데스크톱 GUI 프로그램**입니다.

관리자 화면을 중심으로 학생 정보를 등록·수정·삭제하고, 학생별 출결 현황과 출석률 및 교육 진행률을 확인할 수 있도록 구현했습니다.

---

## 프로젝트 개요

### 개발 목적

교육기관의 학생 정보를 관리하고 출결 현황을 한눈에 확인할 수 있는 관리자용 프로그램을 구현하는 것을 목표로 했습니다.

기본적인 CRUD 기능뿐만 아니라 학생 검색, ID 중복 확인, 출결 데이터 관리 및 출석률·진행률 계산 기능을 구현했습니다.

### 주요 기능

* 학생 정보 조회
* 학생 정보 추가
* 학생 정보 수정
* 학생 정보 삭제
* 학생 정보 검색
* ID 중복 확인
* 학생별 출결 현황 관리
* 출석률 자동 계산
* 교육 진행률 자동 계산
* 학생 데이터 저장 및 불러오기
* 관리자 GUI 제공

## 🖥 주요 기능

### 1. 학생 정보 관리

학생의 기본 정보를 테이블 형태로 관리합니다.

```text
이름
전화번호
생년월일
ID
Password
비고
```

관리자는 학생 정보를 추가, 수정, 삭제할 수 있으며 이름·ID·전화번호 등을 기준으로 학생을 검색할 수 있습니다.

---

### 2. 학생 등록

학생 등록 Dialog를 통해 새로운 학생 정보를 입력합니다.

```text
학생 정보 입력
       │
       ├── 이름
       ├── 전화번호
       ├── 생년월일
       ├── ID
       ├── Password
       └── 비고
              │
              ↓
          ID 중복 확인
              │
              ↓
          학생 정보 등록
```

학생 등록 전에 ID 중복 여부를 확인하도록 구현하여 동일한 ID가 등록되는 것을 방지합니다.

---

### 3. 학생 정보 수정

기존 학생을 선택하여 정보를 수정할 수 있습니다.

학생 수정 시 기존 ID는 변경하지 못하도록 처리하여 학생 식별 정보가 변경되는 문제를 방지했습니다.

---

### 4. 학생 삭제

학생 목록에서 선택한 학생을 삭제할 수 있습니다.

삭제된 학생 정보는 내부 데이터에서도 제거되며 저장 과정을 통해 데이터 파일에 반영됩니다.

---

### 5. 학생 검색

학생 정보를 기준으로 원하는 학생을 검색할 수 있습니다.

검색 대상:

```text
이름
ID
전화번호
```

학생 수가 많아졌을 때 필요한 학생을 빠르게 찾을 수 있도록 구현했습니다.

---

## 📊 출결 관리

학생별 출결 정보를 관리할 수 있습니다.

```text
학생명
전화번호
ID
진도/전체
출석
지각
조퇴
외출
결석
출석률
진행률
```

학생별 출석, 지각, 조퇴, 외출, 결석 횟수를 관리하고 이를 기반으로 출석률과 교육 진행률을 계산합니다.

### 출석률

```text
출석률 = 출석 횟수 / 진행 일수 × 100
```

### 교육 진행률

```text
진행률 = 진행 일수 / 전체 교육 일수 × 100
```

이를 통해 관리자가 학생별 교육 참여 현황을 쉽게 확인할 수 있도록 구성했습니다.

## 💾 데이터 관리

학생 및 출결 데이터는 JSON 형태로 관리합니다.

```text
학생 데이터
    ↓
C++ 객체
    ↓
QJsonObject / QJsonArray
    ↓
QJsonDocument
    ↓
JSON 파일
```

사용한 Qt 클래스:

* `QJsonDocument`
* `QJsonObject`
* `QJsonArray`
* `QFile`

프로그램 실행 시 저장된 데이터를 불러오고, 학생 정보가 변경되면 데이터를 저장하는 방식으로 구성했습니다.

## 💡 구현하면서 경험한 내용

### Qt GUI 개발

Qt Widgets를 활용하여 데스크톱 GUI를 구성하고 버튼, 테이블, Dialog 등의 UI 컴포넌트를 사용했습니다.
